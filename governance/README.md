# STRling Engineering Governance

This directory contains durable engineering policy and the foundational
contracts used to govern architectural work.

- `ENGINEERING_CONSTITUTION.md` is the normative engineering policy.
- `authority.md` defines precedence when project artifacts disagree.
- `architecture.md` defines target architectural invariants.
- `schemas/` contains machine-readable governance contract schemas.
- `templates/` contains starting records that conform to those schemas.

These artifacts govern engineering work; they do not define STRling language
syntax or semantics.
