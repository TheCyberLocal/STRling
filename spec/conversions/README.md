# Canonical semantic conversions

This directory owns versioned product contracts for deterministic projections
from canonical STRling semantics into already-defined authoring surfaces. A
conversion contract does not define new language semantics or replace the
destination frontend contract.

The currently defined conversion is
[`strling.semantic-conversion@1.0.0`](semantic/1.0/README.md), from validated
canonical Semantic IR to Semantic STRling text or a direct-operation Simply
BuilderRequest.
