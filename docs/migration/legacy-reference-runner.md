# Historical legacy-reference runner

> Retired in the Fourth Edition P19 semantic-authority cleanup. This page is a
> non-normative migration record, not current tooling guidance.

The former TypeScript and Python reference runners captured implementation-era
observations for differential migration work. Their executable code, root
commands, and profile operations have been removed. The two frozen corpus JSON
documents remain under `tooling/legacy_reference/` as data-only archaeology and
cannot feed product, specification, generation, or certification authority.

Current correctness is established by specification-authored contracts,
canonical structured certification, governed semantic data, and real-engine
evidence. `python -m tooling.semantic_authority --check --json` enforces that
boundary.
