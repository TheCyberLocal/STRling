# Historical full-corpus differential

> Retired in P19. This page is non-normative history.

The former full-corpus differential joined historical TypeScript/Python
observations with canonical replacement checks. It was useful during migration,
but implementation-derived observations are no longer a required certification
denominator. The comparison engine, baseline, root command, tests, and profile
operation have been removed.

Current profiles instead require the structured semantic-authority hardgate,
canonical conformance, migration-explanation certification, target/adapter
certification, and real-engine evidence.
