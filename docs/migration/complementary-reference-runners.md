# Historical complementary reference runners

> Retired in P19. This document records migration provenance only.

The complementary TypeScript and Python runners once provided independent
implementation-era observations. They were deliberately isolated from normative
contracts, but their required profile status still allowed historical behavior
to influence certification. P19 removed the executables and replaced their
decision role with structured/spec-authored authority.

Only the frozen JSON corpora remain, under an enforced data-only boundary. They
may be inspected for archaeology but cannot execute, generate expectations, or
determine correctness.
