## Issue 1 — `feat(emitter): detect variable-length lookbehind in Pcre2Emitter`

**Priority:** HIGH (security/correctness — spec-mandated; currently a silent failure)
**Affects:** All 17 bindings. Implement first in TypeScript reference, then propagate.

### Target Vector

-   Reference: [`bindings/typescript/src/STRling/emitters/pcre2.ts`](../../bindings/typescript/src/STRling/emitters/pcre2.ts)
-   Then: every `bindings/<lang>/.../pcre2.{rs,py,swift,go,java,cs,cpp,rb,kt,lua,pl,php,r,dart,fs}` and `bindings/c/src/strling.c`.

### Container

A new pre-emission AST walker invoked at the top of `emit()`:

```ts
function assertNoVariableLengthLookbehind(node: AstNode): void {
    // …
}
```

### Logic Gap

Walk every `Lookbehind` / `NegativeLookbehind` subtree. If any descendant is an
unbounded `Quantifier` (`*`, `+`, `{n,}`) **or** a top-level `Alternation` whose
branches differ in fixed length, raise:

```
STRlingEmitterError("PCRE2 lookbehind must be fixed-length. "
  + "The pattern '(?<=a+)' uses an unbounded quantifier inside a lookbehind, "
  + "which PCRE2 cannot compile. "
  + "Replace the unbounded quantifier with a bounded range: '(?<=a{1,8})'.")
```

The message must satisfy the **Signpost Pattern** (state / explain / direct).

### Verification

Add a test fixture `tests/conformance/inputs/lookbehind-vlb-rejected.json`
with an AST containing `Lookbehind(Quantifier(Literal("a"), "+"))` and an expected
artifact:

```json
{ "errors": [{ "code": "VLB_NOT_SUPPORTED", "engine": "pcre2" }] }
```

Add per-binding tests:

-   `bindings/typescript/__tests__/e2e/pcre2_emitter.test.ts` → `it("rejects variable-length lookbehind")`
-   `bindings/python/tests/e2e/test_pcre2_emitter.py` → `def test_rejects_variable_length_lookbehind`
-   `bindings/swift/Tests/STRlingE2ETests/E2EPCRE2EmitterTests.swift` → `func testRejectsVariableLengthLookbehind`
-   `bindings/c/tests/unit/emitter_edges_test.c` → `test_rejects_variable_length_lookbehind`

## Issue 2 — `feat(emitter): enforce MAX_AST_DEPTH guard before emission`

**Priority:** HIGH (DoS / stack-exhaustion vector)
**Affects:** All emitters and all parsers.

### Target Vector

-   New constant in [`spec/grammar/semantics.md`](../../spec/grammar/semantics.md): `MAX_AST_DEPTH = 256`.
-   Reference implementation in [`bindings/typescript/src/STRling/emitters/pcre2.ts`](../../bindings/typescript/src/STRling/emitters/pcre2.ts).

### Container

```ts
const MAX_AST_DEPTH = 256;
function assertDepth(node: AstNode, depth = 0): void {
    if (depth > MAX_AST_DEPTH) throw new STRlingEmitterError(/*…*/);
    // …recurse into children…
}
```

### Logic Gap

Walk the AST iteratively (or with explicit depth counter) before emission.
On exceeding `MAX_AST_DEPTH`, raise a Signpost-pattern error:

> `"AST nesting depth exceeded the safe limit of 256. Deeply nested patterns can exhaust the stack on some hosts and slow down PCRE2 compilation. Flatten nested groups or split the pattern into composed sub-patterns."`

### Verification

`tests/conformance/inputs/depth-limit-exceeded.json`: programmatically
generated AST with 1,024 nested `Group` nodes. Per-binding test:

```py
def test_max_ast_depth_enforced():
    ast = nested_group(depth=1024)
    with pytest.raises(STRlingEmitterError, match="nesting depth"):
        emit_pcre2(ast)
```

Mirror in `EmitterEdgesTests.swift`, `emitter_edges_test.c`, etc.

## Issue 3 — `feat(emitter): emit REDOS_RISK warning for nested unbounded quantifiers`

**Priority:** HIGH (spec-mandated, currently absent)
**Affects:** All bindings. The warning channel (`TargetArtifact.warnings`) already exists per [`semantics.md#L361-L398`](../../spec/grammar/semantics.md#L361).

### Target Vector

[`bindings/typescript/src/STRling/emitters/pcre2.ts`](../../bindings/typescript/src/STRling/emitters/pcre2.ts) — new analyzer pass.

### Container

```ts
function detectRedosRisks(node: AstNode, warnings: Warning[]): void {
    // …
}
```

### Logic Gap

Detect:

1. **Nested unbounded quantifiers**: `Quantifier(Quantifier(_, '+'|'*'|'{n,}'), '+'|'*'|'{n,}')` — emit `REDOS_RISK`.
2. **Quantified alternation with overlapping branches**: `Quantifier(Alt(a, b), '+'|'*')` where `intersect(first(a), first(b)) ≠ ∅` — emit `REDOS_RISK` with hint to use atomic group.
3. **Adjacent overlapping quantifiers**: `Concat(Quantifier(a, '+'), Quantifier(a, '+'))`.

Each warning payload follows the existing schema:

```json
{
    "code": "REDOS_RISK",
    "message": "...",
    "node": "<id>",
    "fix": "Use atomic group `(?>…)` or possessive `++`."
}
```

### Verification

Add fixtures:

-   `tests/conformance/inputs/redos-nested-plus.json` — `(a+)+`
-   `tests/conformance/inputs/redos-overlapping-alt.json` — `(a|a)+`
-   `tests/conformance/inputs/redos-safe-atomic.json` — already exists; ensures no false positive.

Per-binding tests assert `artifact.warnings.some(w => w.code === 'REDOS_RISK')`.

## Issue 5 — `test(emitter): property-based fuzzing of Pcre2Emitter (Python reference)`

**Priority:** MEDIUM
**Affects:** Python first; later Rust (`proptest`), Java (`jqwik`), TypeScript (`fast-check`).

### Target Vector

New file `bindings/python/tests/fuzz/test_pcre2_emitter_fuzz.py`.

### Container

```py
from hypothesis import given, settings, strategies as st
from STRling.emitters.pcre2 import emit

ast_strategy = st.recursive(
    st.one_of(literal_strategy, char_class_strategy),
    lambda children: st.one_of(
        group_strategy(children),
        alt_strategy(children),
        quantifier_strategy(children),
        lookaround_strategy(children),
    ),
    max_leaves=64,
)

@given(ast_strategy)
@settings(max_examples=2000, deadline=None)
def test_emit_never_crashes_pcre2(ast):
    artifact = emit(ast)
    # All produced patterns must compile in PCRE2
    pcre2.compile(artifact.pattern, options=artifact.flags)
```

### Logic Gap

Build composable Hypothesis strategies that cover every AST node type
(`Literal`, `CharClass`, `Group`, `Alt`, `Quantifier`, `Lookahead`,
`Lookbehind`, `Backreference`, `NamedCapture`). Constrain depth to
`MAX_AST_DEPTH - 1` so depth-guard rejects are not counted as failures.

### Verification

Run with `pytest bindings/python/tests/fuzz/ -q --hypothesis-seed=0`. The job
must complete within 5 minutes on CI and produce zero `pcre2.PatternError`
exceptions. A failing seed must be auto-saved to
`bindings/python/tests/fuzz/.hypothesis/`.

## Issue 6 — `test(emitter): Unicode property edge-case fixtures`

**Priority:** MEDIUM
**Affects:** Conformance suite + every emitter.

### Target Vector

-   `tests/conformance/inputs/unicode-properties-extended.json`
-   `tests/conformance/expected/pcre2/unicode-properties-extended.json`

### Container

A single fixture exercising:

-   Unicode 16 scripts (`\p{Garay}`, `\p{Tulu_Tigalari}`, `\p{Kawi}`)
-   `\p{Emoji}` and `\p{Emoji_Presentation}`
-   Negated forms (`\P{L}`, `\P{Sc}`)
-   Invalid property name (`\p{NotAProperty}`) — must produce
    `STRlingParseError`, **not** a PCRE2 compile error.
-   Surrogate-range literal handling (`\u{D800}` → must be rejected per spec).

### Logic Gap

Validate each binding's emitter:

1. Maps script names to PCRE2's exact spelling (some require aliases).
2. Rejects invalid property names at parse time, with Signpost-pattern hint.
3. Refuses raw surrogate code points in literals.

### Verification

Each binding's `pcre2_emitter` test file gets a `unicode_properties_extended`
case that loads the fixture and asserts pattern equality + warnings list.
