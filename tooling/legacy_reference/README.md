# Historical reference corpora

This directory contains two frozen implementation-era observation corpora:
`corpus.json` and `python_corpus.json`. They are retained only as non-normative
migration archaeology.

No executable runner, generator, profile operation, product package, or
certification producer may consume these files as semantic truth. Current
correctness comes from specification-authored contracts, canonical structured
certification, governed semantic data, and real-engine evidence. The repository
semantic-authority check enforces this data-only boundary.
